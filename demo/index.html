table-export-extension

A Chrome and Edge extension that exports any table on a web page to CSV or XLSX, or copies it as tab-separated text for Excel and Google Sheets. This page runs the extension's own export code on the sample tables below, so you can try it without installing anything.

Nothing leaves this page. Files are made in your browser and saved by you.

Install the extension

    
    
      
  1. Download table-export-extension-v0.1.0.zip from the latest release and unzip it.
    2. 
      
  2. Open chrome://extensions (or edge://extensions) and turn on Developer mode.
    3. 
      
  3. Choose Load unpacked and select the unzipped folder.
    4. 
      
  4. Open any page with a table and click the toolbar icon. Tables are outlined in blue; the one you pick turns orange.
    5. 
    

    
It asks only for activeTab, scripting and downloads. No host permissions, no network requests, no stored data.

  

  
The same TypeScript modules as the extension (src/parse.ts, src/transform.ts, src/format.ts), bundled for this page with esbuild.
